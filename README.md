# euappsolutions.com

The European Apps Solutions website. Static HTML generated by a small Python script,
no framework and no build dependencies beyond the standard library — served straight
from this repository by GitHub Pages.

Replaces the previous WordPress + Elementor site.

## Layout

```
index.html  apps/  about/  contact/     generated pages — do not edit by hand
privacy-policy-looksmax/                generated, but the text is verbatim from the old site
terms-of-use-wristtube/  term-of-use/
assets/css  assets/js  assets/img       hand-written CSS/JS, generated imagery
src/                                    everything that produces the above
  apps.json          app data: curated copy + live App Store numbers
  legal/*.html       legal body text, extracted once from the WordPress pages
  build.py           generates every page
  make_apps_json.py  curated copy lives here; merges in live App Store metadata
  fetch_assets.py    downloads icons + screenshots, converts to webp
  make_social.py     og.png and apple-touch-icon.png
  check.py           post-build link/asset/SEO checks
  extract_legal.py   one-off scraper for the legal text (only rerun if it's amended)
```

Pages are written to the repo root so Pages can serve the branch directly.
`.nojekyll` stops Jekyll touching anything.

## Rebuild

```bash
./build.sh
```

That refreshes ratings from the App Store, downloads any new artwork, regenerates
every page and then verifies the output. To build without network access:

```bash
./build.sh --offline
```

Preview locally:

```bash
python3 -m http.server 4173
```

## Editing content

- **App copy** (name, tagline, blurb, category grouping) — `CURATED` in
  `src/make_apps_json.py`, then rebuild. Ratings, prices, categories, artwork and
  last-updated dates all come from Apple; don't hand-edit those.
- **Adding an app** — add a row to `CURATED` with its bundle ID. The build refuses
  any app whose App Store seller isn't `European apps solutions LTD`, so a typo
  fails loudly rather than publishing someone else's app.
- **Retiring an app** — remove it from `CURATED` and add its old slug to `RETIRED`
  in `src/build.py`, so the URL keeps explaining itself instead of 404ing.
- **Page copy** (home, about, contact) — the `page_*` functions in `src/build.py`.
- **Design** — `assets/css/site.css`. Tokens at the top; dark mode is a token swap.

## URLs kept from the old site

These are cited from App Store listings and must not move:

| URL | Why |
| --- | --- |
| `/privacy-policy-looksmax/` | privacy policy URL on App Store listings |
| `/terms-of-use-wristtube/` | terms URL on App Store listings |
| `/term-of-use/` | older terms URL |
| `/apps/<slug>/` | app pages kept their original slugs where the app is still ours |

`/apps/wump/`, `/apps/finger-picker/` and `/apps/my-smart-keys/` are kept as
explanatory pages: the first two are now published by other companies, the third is
no longer on the store.

The legal text is reproduced verbatim from the WordPress pages. If it needs amending,
edit `src/legal/*.html` — don't re-run `extract_legal.py`, which would overwrite it
from the old site.

## Deploying

Repository: `TheEUAppSolutions/euappsolutions.com`. GitHub Pages serves it directly —
there is no build step on their side, so whatever is committed is what ships.

Two branches, because the domain hasn't moved yet:

| Branch | Built with | Serves | Purpose |
| --- | --- | --- | --- |
| `main` | `./build.sh` (root paths, has `CNAME`) | `euappsolutions.com` | the real site, **after** the DNS cutover |
| `preview` | `python3 src/build.py --base /euappsolutions.com`, no `CNAME` | [theeuappsolutions.github.io/euappsolutions.com](https://theeuappsolutions.github.io/euappsolutions.com/) | reviewable today |

Pages currently points at `preview`. A `CNAME` file makes Pages serve *only* the custom
domain and redirect the `github.io` URL to it — which would be a dead end until DNS
moves, hence the split. `preview` also carries a `Disallow: /` robots.txt so the staging
copy stays out of search; the canonical tags already point at the real domain.

### Updating the preview

```bash
git checkout preview && git merge main
python3 src/build.py --base /euappsolutions.com
rm -f CNAME && printf 'User-agent: *\nDisallow: /\n' > robots.txt
git commit -am "Refresh preview" && git push
```

### Cutover, once DNS is pointed

1. Confirm the A records below resolve: `dig +short euappsolutions.com`
2. Point Pages at `main`:
   `gh api -X PUT repos/TheEUAppSolutions/euappsolutions.com/pages -f 'source[branch]=main' -f 'source[path]=/'`
3. Check `https://euappsolutions.com/privacy-policy-looksmax/` returns 200 — App Store
   listings cite it.
4. Delete the old WordPress site only after that passes.

**DNS is the one piece that isn't in this repo.** `euappsolutions.com` is on Google
nameservers in an account that isn't reachable from the usual dev login, so the
cutover needs whoever holds that zone. The records Pages needs:

```
A     euappsolutions.com   185.199.108.153
A     euappsolutions.com   185.199.109.153
A     euappsolutions.com   185.199.110.153
A     euappsolutions.com   185.199.111.153
CNAME www                  <org>.github.io.
```

`dashboard.euappsolutions.com` is a separate Cloud Run mapping and is unaffected.
